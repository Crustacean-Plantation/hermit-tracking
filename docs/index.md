# Hermit tracking

Open problem from Crustacean Plantation Inc.

The current trail follows streets because an AirTag reports the phone that heard it, not the crab. This page asks for an honest logger, or a lighter way to track *Coenobita clypeatus* in the Florida Keys.

Full brief: [problem.md](problem.md).
